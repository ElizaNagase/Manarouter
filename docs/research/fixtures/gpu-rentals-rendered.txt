# The GPU rentals view, as a browser rendered it

Captured 2026-11-12 06:13 from the working tree, not from a mock:
headless Chromium loaded the real panel (`panel/` served by `tools/panel-lab/serve.mjs`), which
proxied `/api` to a throwaway conductor on 127.0.0.1:20999 holding one synthetic account and one
synthetic deployment. The text below is every visible string in the rendered document, in document
order, with tags stripped — so it is the page a person would read, not the source that produced it.

The credential in this capture is the synthetic `wk-SYNTHETICID0001` / `SYNTHETICsecret0001` pair
described in `README.md`; it exists only in a throwaway vault under /tmp and has never been valid.

What this capture is evidence for:
  * the plan table, accounts table, deployments table, bundle panel and catalogue all render with
    live data from the four `/api/gpu/*` routes (the fields are not `undefined` or empty);
  * the sessions cell reads `~6 of 6` — a derived figure against the configured ceiling;
  * `(Paid)` appears on H100 and on nothing else, which is the requirement-10 decision made visible;
  * B300's VRAM column is an em dash rather than a guessed number;
  * the bundle panel says the record does not carry its app text and shows the command only.

What it is not evidence for: that any of those numbers is correct (the sizing fixtures and the Rust
tests carry that argument), or that the view is pleasant — a text capture cannot judge layout.

Deployment bundle — rental-mana-modal-qwen3-8-27b-uncensored-fp8
Modal publishes no deployment REST API. Manarouter cannot deploy for you: it generates the app file and the exact command, and this bundle is the deployment. Run the command yourself.
Modal has no public REST endpoint that deploys or updates an app; deployment goes through the `modal` CLI or `modal.App.deploy()` from a Python process. The conductor therefore generates the app and the operator deploys it — it never claims to have deployed anything itself.
The deployment record does not carry its generated app text, so the panel shows the command only rather than reconstructing a file it cannot see. Re-run the setup flow to regenerate the bundle.
